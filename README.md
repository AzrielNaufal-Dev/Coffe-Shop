# Seduh Aja

A responsive landing page for Seduh Aja, a coffee shop. It showcases the shop's best-selling drinks, story, and contact information.

## Features

- Responsive navigation with a mobile menu.
- Dedicated hero, best sellers, about, and contact sections.
- Entrance animations on page load and scroll-triggered reveal animations.
- Hover interactions for best-selling product cards.
- Optimized WebP images, with eager loading for the hero and lazy loading for supporting content.
- Respects the user's `prefers-reduced-motion` accessibility setting.

## Built With

- HTML5
- Tailwind CSS via CDN
- CSS
- Vanilla JavaScript (no additional animation libraries or frameworks)

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Ensure you have an internet connection so Tailwind CSS can load from its CDN.
